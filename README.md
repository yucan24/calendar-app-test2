# NSCT-U15BBC webapp

バスケットボールチーム向けの予定共有・出欠管理・請求管理・会計管理アプリです。

管理者は予定作成、会員管理、月謝や遠征費などの請求、指導者勤務、月次会計レポートを管理できます。ユーザーはログイン後にカレンダー確認、出欠回答、未払い項目の確認を行います。

## 主な機能

- ログイン
  - Supabase Authではなく、名前＋数字4桁でログインする。4桁をbcryptでハッシュ化し、平文は保存しない。
  - 32バイトのランダムトークンによるサーバー検証型セッションを使用。DBにはトークンのSHA-256だけを保存する。
  - ログアウト、ログイン停止、コード・権限変更でセッションを失効させる。ログイン試行回数はDBで制限する。
  - 同じブラウザーのタブはログイン状態を共有し、別タブのログイン・ログアウトを画面へ同期。古い画面からの送信を止め、別の管理者へ切り替わった会員管理の操作もサーバーで拒否する。
  - ログイン後は権限にかかわらず本人分の支払い確認を表示。管理者は確認後に管理者画面、一般会員はカレンダーへ進む。管理者の一覧からも支払い確認を開き直せる。

- カレンダー
  - 管理者による予定作成・編集。
  - ユーザーによる出欠回答。
  - 期間予定、休み、表示色などに対応。

- 会員管理
  - 登録申請の承認。
  - 会員情報の編集。
  - 承認待ち・初期設定待ち・利用中・停止・削除済みの状態と管理者権限を管理（本番・テストに反映済み）。
  - 申請通知・初期設定・確認・再設定メールを自動送信し、失敗時は管理画面から再送。
  - 本人用のアカウント設定と、期限付き・一度限りの復旧リンク。
  - 会員削除時は請求・勤怠などの履歴を保持し、停止・削除後も会計を維持。

- 請求管理
  - 月謝、遠征費、大会費、ユニフォーム代、その他請求の登録。
  - 未払い、支払い済み、免除の状態管理。
  - 返金項目の管理。
  - 管理者が対象月・費目を選び、未払いメールの宛先と本文を確認してアプリ内から個別送信。メールアプリへの移動は不要。
  - 確認済みの登録メールを使用し、送信結果・履歴を表示。送信直前の請求変更を検知し、同じ会員への5分以内の再送と同じ要求の二重送信を防止。定期自動配信は行わない。

- 指導者勤怠・立替管理
  - 指導時間、事務時間、交通費、その他立替の記録。
  - カレンダーと共通の月・週・日表示。日付・予定からの入力、複数日登録、指導者別の月間集計。

- 会計管理
  - 月謝、遠征費などの支払済み請求、協賛金、その他収入の集計。
  - 指導者報酬、源泉税、その他出費の集計。
  - 支払済み返金、交通費・立替経費も出費に含む。
  - 指導者別の報酬・税額・手取り表示。
  - 交通費・立替経費は報酬と合算して振込額に加える。
  - 指導者の請求は、精算完了時に報酬と相殺して支払済みにする。取消時は未払いへ戻す。
  - 振込額0円の場合は「振込なしで相殺を確定」できる。
  - 月次レポートの画像出力。

- 銀行明細照合（会計管理画面内）
  - 八十二銀行形式のCP932 / Shift_JIS・UTF-8 CSVを取込（5MB・5,000明細まで）。
  - 口座ごとに重複を判定。同じ取引番号で内容が変わっていた場合は上書きせず警告する。
  - 未払い請求、返金、収入・出費、指導者への送金、源泉税納付へ手動で紐付ける。
  - 指導者への送金・源泉税納付は分割処理でき、照合済み額と残額を表示する。
  - 処理済み・対象外の履歴確認、紐付け取消に対応。

- 開発者への意見
  - DB保存ではなく、固定メールアドレス宛の `mailto:` で送信する。

## 会計機能の更新（2026-11-20）

会計の相殺記録・口座別識別・取込警告に対応し、現在は初期設定リンクの権限変更時の保持に対応する `20261124010000_preserve_setup_links_on_role_change.sql` まで適用済みです。`20261120020000_preserve_legacy_profile_and_ticket_data.sql` で旧プロフィールのフラグ・指導記録の状態・回数券残数も保持しています。テスト用seedを本番へ投入しないでください。

- 相殺は全額を精算できる請求単位で行います。報酬を超える請求や、請求の一部だけの相殺は未払いとして残します。対象は報酬と同じ月の請求です。

- 月次の端数処理・相殺を月ごとに合計して累計収支を計算します。
- 過去に保存された不正対象月はmigrationで削除・変換しません。新規・更新分だけを拒否します。公開前に既存データを調査・訂正してください。

## UIの共通ルール

- 画面上部は `src/components/ui/PageHeader.tsx` を使用。戻る操作は左上の `BackLink`、ログアウトや設定は右側の操作欄に揃える。
- 一覧の機能カードは `MenuCard` を使い、管理者・一般会員とも画面幅にかかわらず1列表示。カレンダー・指導者勤怠は `CalendarToolbar` で月・週・日と表示期間を切り替える。会計の月送りは `MonthNavigation` を使う。
- 管理者の一覧は、カレンダー → 指導者勤怠・立替管理 → 支払い確認 → アカウント設定 → 会計管理 → ユーザー・請求管理 → 会員管理の順に配置する。
- 保存・送信は `ui-button ui-button-primary`、通常操作は `ui-button-secondary`、削除・停止は `ui-button-danger`。共通の高さは44px以上。ユーザー指定により、カレンダーの操作欄はスマホで28px・大画面で最大40pxに調整する。期間予定の帯はスマホ月表示約16px・週表示約24pxを基準にし、月表示は大画面の文字サイズに追従する。
- 入力欄は `ui-field`、カードは `ui-card`、タブは `ui-tab`、モーダルは `ui-modal`、閉じる操作は `ui-icon-button`。見た目は `globals.css` の共通クラスで調整する。
- 出欠・支払い状態・予定色は意味を持つ色分けとして保持。説明文を増やさず、項目名・操作・状態で構成する。新しい画面でも同じ部品・クラスを使い、画面ごとの装飾を増やさない。
- スマホでは会計・取込履歴の表を項目名付きのカードへ切り替え、タブを折り返す。カレンダーの月表示は7列・全角6文字、週表示は7日分の縦並び、日表示は時間軸とする。日表示の予定枠は時間に応じた高さにし、短い予定は詳細で全文を確認できる。確認ダイアログは画面内でスクロールできるようにする。
